# YouTube Viewer - Глобальное использование

## ✅ Приложение работает везде!

Это приложение использует **двухуровневую архитектуру** для обеспечения доступа к YouTube видео во всех странах и регионах:

### 🎯 Способ 1: YouTube Player API (ОСНОВНОЙ)
- **Как работает**: Использует официальный API YouTube для встроенного плеера
- **Где работает**: Европа, США, большинство Азии, Россия
- **Преимущества**: Лучшее качество, адаптивное потокование, встроенные элементы управления
- **Статус**: ✅ Протестировано и работает

### 🎯 Способ 2: Fallback через yt-dlp (ДЛЯ БЛОКИРОВКИ)
- **Как работает**: Автоматически извлекает MP4 URL при блокировке плеера
- **Где работает**: Куба, Иран, регионы с блокировкой YouTube
- **Преимущества**: Работает даже когда YouTube заблокирован
- **Требует**: Cookie аутентификация (опционально)

## 📋 Как это работает

### Стандартное воспроизведение видео:
```
1. Пользователь ищет видео → API YouTube находит его
2. Кликает на видео → загружается YouTube Player API
3. Плеер отображается и воспроизводится видео
4. Если ошибка → JavaScript ловит ошибку и загружает fallback
```

### При блокировке в регионе:
```
1. YouTube Player API получает ошибку (код 100, 101 или 150)
2. Срабатывает обработчик ошибок (onPlayerError)
3. Автоматически загружается HTML5 плеер с прямым MP4 URL
4. Видео воспроизводится через yt-dlp извлеченную ссылку
```

## 🔧 Настройка для максимальной совместимости

### Если yt-dlp требует cookie (для Кубы):

1. **Получить cookie из браузера** (Firefox/Chrome):
   - Откройте YouTube в браузере
   - DevTools → Storage → Cookies → youtube.com
   - Скопируйте все cookies

2. **Добавить в приложение**:
   ```bash
   # Сохраните cookies в файл
   echo "cookies_content" > cookies.txt
   ```

3. **Приложение автоматически использует их**

## 📊 Тестирование подключения

### Проверить основной способ:
```bash
curl -I http://localhost:5000/video/FJb48bzI1Gk
```
Если статус 200 → основной способ работает ✅

### Проверить поиск (работает везде):
```bash
curl http://localhost:5000/api/search?q=путешествие
```
Если вернул JSON → поиск работает ✅

### Проверить fallback:
```python
import yt_dlp

ydl = yt_dlp.YoutubeDL({'format': 'best[ext=mp4]'})
info = ydl.extract_info('https://www.youtube.com/watch?v=VIDEO_ID', download=False)
print(info.get('url'))  # Прямая ссылка на MP4
```
