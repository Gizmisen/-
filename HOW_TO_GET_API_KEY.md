# 🔑 Как получить YouTube API ключ (пошаговая инструкция)

## Шаг 1: Откройте Google Cloud Console

1. Перейдите на сайт: **https://console.cloud.google.com/**
2. Войдите в свой Google аккаунт (если еще не вошли)

## Шаг 2: Создайте новый проект

1. Нажмите на выпадающее меню проектов (вверху слева, рядом с "Google Cloud")
2. Нажмите **"NEW PROJECT"** (Создать проект)
3. Введите название проекта, например: `YouTube Viewer`
4. Нажмите **"CREATE"** (Создать)
5. Подождите несколько секунд, пока проект создастся

## Шаг 3: Включите YouTube Data API v3

1. В левом меню выберите **"APIs & Services"** → **"Library"**
   - Или перейдите напрямую: https://console.cloud.google.com/apis/library
2. В поисковой строке введите: `YouTube Data API v3`
3. Нажмите на **"YouTube Data API v3"**
4. Нажмите синюю кнопку **"ENABLE"** (Включить)
5. Подождите, пока API активируется

## Шаг 4: Создайте API ключ

1. В левом меню выберите **"APIs & Services"** → **"Credentials"**
   - Или перейдите: https://console.cloud.google.com/apis/credentials
2. Нажмите **"+ CREATE CREDENTIALS"** (вверху)
3. Выберите **"API key"**
4. Появится окно с вашим API ключом - **СКОПИРУЙТЕ ЕГО!**
   - Он будет выглядеть примерно так: `AIzaSyD1234567890abcdefghijklmnopqrstu`

## Шаг 5: (Опционально) Ограничьте ключ для безопасности

1. После создания ключа нажмите **"RESTRICT KEY"**
2. В разделе **"API restrictions"**:
   - Выберите **"Restrict key"**
   - Выберите только **"YouTube Data API v3"**
3. Нажмите **"SAVE"**

## Шаг 6: Установите ключ в приложение

Выберите один из способов:

### Способ 1: Переменная окружения (рекомендуется)
```bash
export YOUTUBE_API_KEY="AIzaSyВАШ_КЛЮЧ_ЗДЕСЬ"
```

### Способ 2: Файл .env
Создайте файл `.env` в корне проекта:
```bash
echo "YOUTUBE_API_KEY=AIzaSyВАШ_КЛЮЧ_ЗДЕСЬ" > .env
```

### Способ 3: Прямо в config.py
Откройте файл `config.py` и замените:
```python
YOUTUBE_API_KEY = os.environ.get('YOUTUBE_API_KEY') or 'AIzaSyВАШ_КЛЮЧ_ЗДЕСЬ'
```

## Шаг 7: Запустите приложение

```bash
python app.py
```

Откройте браузер: **http://localhost:5000**

## 📊 Квоты и ограничения

- **Бесплатная квота**: 10,000 единиц в день
- **Стоимость операций**:
  - Поиск видео: 100 единиц
  - Информация о видео: 1 единица
  - Это означает ~100 поисковых запросов в день бесплатно

## ❓ Частые проблемы

### "API key not valid"
- Убедитесь, что YouTube Data API v3 включен
- Проверьте, что ключ скопирован полностью (без пробелов)
- Подождите 2-3 минуты после создания ключа

### "Access Not Configured"
- YouTube Data API v3 не включен для проекта
- Вернитесь к Шагу 3

### "Quota exceeded"
- Вы превысили дневной лимит 10,000 единиц
- Подождите до следующего дня (сбрасывается в полночь по тихоокеанскому времени)
