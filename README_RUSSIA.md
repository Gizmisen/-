## 🔧 Если не работает поиск

**Проверьте API ключ:**
```bash

from config import Config
print(f"API ключ установлен: {bool(Config.YOUTUBE_API_KEY)}")
print(f"Первые символы: {Config.YOUTUBE_API_KEY[:10]}...")
EOF
```

## 🎯 Что можно делать

1. **Поиск видео** - ищите любые видео на русском или английском
2. **Просмотр видео** - встроенный YouTube плеер с высоким качеством
3. **Информация о видео** - просмотры, лайки, комментарии, дата публикации
4. **API доступ** - используйте `/api/search` и `/api/video` для интеграции

## 🚨 Если появится ошибка видео в браузере

Это нормально! Система автоматически:
1. Попробует загрузить YouTube Player API
2. Если не получится - переключится на HTML5 плеер с прямым видео
3. Видео все равно будет воспроизведено

## 💡 Советы

- **Первый запуск может быть медленным** - это нормально, идет загрузка библиотек
- **Поиск работает везде** - даже если плеер заблокирован
- **Можно запустить на сервере** - приложение работает на любом Linux/Mac/Windows
