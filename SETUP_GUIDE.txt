┌───────────────────────────────────────────────────────────────┐
│ ШАГ 1: ПОЛУЧИТЕ YouTube API КЛЮЧ                             │
└───────────────────────────────────────────────────────────────┘

   1. Откройте: https://console.cloud.google.com/
   
   2. Создайте новый проект:
      • Нажмите "NEW PROJECT"
      • Введите название (например: "YouTube Viewer")
      • Нажмите "CREATE"
   
   3. Включите YouTube Data API v3:
      • Меню → "APIs & Services" → "Library"
      • Найдите "YouTube Data API v3"
      • Нажмите "ENABLE"
   
   4. Создайте API ключ:
      • Меню → "APIs & Services" → "Credentials"
      • Нажмите "+ CREATE CREDENTIALS"
      • Выберите "API key"
      • СКОПИРУЙТЕ ключ!
   
   📖 Подробно: cat HOW_TO_GET_API_KEY.md

┌───────────────────────────────────────────────────────────────┐
│ ШАГ 2: УСТАНОВИТЕ API КЛЮЧ                                   │
└───────────────────────────────────────────────────────────────┘

   В терминале выполните:
   
   export YOUTUBE_API_KEY="ваш_ключ_здесь"
   
   Или создайте файл .env:
   
   echo "YOUTUBE_API_KEY=ваш_ключ" > .env

┌───────────────────────────────────────────────────────────────┐
│ ШАГ 3: ПРОВЕРЬТЕ КЛЮЧ (ОПЦИОНАЛЬНО)                          │
└───────────────────────────────────────────────────────────────┘

   ./check_api_key.sh
   
   Скрипт автоматически проверит:
   ✅ Установлен ли ключ
   ✅ Работает ли он
   ✅ Включен ли YouTube API

┌───────────────────────────────────────────────────────────────┐
│ ШАГ 4: ЗАПУСТИТЕ ПРИЛОЖЕНИЕ                                  │
└───────────────────────────────────────────────────────────────┘

   python app.py
   
   Откройте браузер: http://localhost:5000

┌───────────────────────────────────────────────────────────────┐
│ 🆘 ВОЗНИКЛИ ПРОБЛЕМЫ?                                        │
└───────────────────────────────────────────────────────────────┘

  ❌ "API key not valid"
     → Проверьте правильность ключа
     → Убедитесь, что YouTube Data API v3 включен
  
  ❌ "Access Not Configured"
     → YouTube Data API v3 не включен в проекте
     → Вернитесь к Шагу 1, пункт 3
  
  ❌ "Quota exceeded"
     → Превышен дневной лимит (10,000 единиц)
     → Подождите до следующего дня
  
  🔍 Диагностика:
     ./check_api_key.sh
