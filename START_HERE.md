## 🚨 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема: "Модуль не найден"
```bash
pip install -r requirements.txt
```

### Проблема: "Порт 5000 уже занят"
```bash
# Найти процесс
lsof -i :5000

# Убить процесс
kill -9 <PID>

# Или используйте другой порт
python app.py --port 5001
```

### Проблема: "API ключ не работает"
```bash
# Проверить ключ
python3 << 'EOF'
from config import Config
print(Config.YOUTUBE_API_KEY)
EOF
```

### Проблема: "Видео не воспроизводится"
- Это нормально! Система автоматически переключится на fallback
- Видео все равно будет воспроизведено
